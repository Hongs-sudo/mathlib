# 수학도서관

수학도서관 원장님·선생님이 함께 쓰는 앱 (https://hongs-sudo.github.io/mathlib/).
내신분석 앱과 오답노트 앱을 하나로 합친 것입니다.

- 홈: 다가오는 시험(나이스 D-day) · 새 소식 · 할 일 · 바로가기
- 자료함: 교재 · 기출 · 학교 프린트 · 학원 교재 (Firestore `sources`), MYBOX 교재 폴더 연결
- 학생: 교재 오답 입력 → 1차 오답노트 만들기 · 인쇄 / 시험 결과 → 학생 분석지
- 분석지 · 학교별 분석 · 시험 등록 · 단원·유형 · 선생님 관리 (내신분석과 같음)

데이터는 Firebase `sudo-naesin`에만 있습니다. 이 저장소에는 시험지·학생 데이터를 넣지 않습니다.
권한은 `firestore.rules` (원장 > 원장(공동) > 관리자 > 선생님: 본인이 등록한 학생만).
AI(시험 분석·오답노트 재타이핑·풀이)는 원장님이 버튼을 누를 때만 씁니다.
